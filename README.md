# UniAssist AI

Навчальна концепція ШІ-асистента студента ХНУРЕ: чат-бот (Telegram, веб),
який відповідає на довідкові запитання за офіційними документами
і вказує джерело відповіді.

> Статус: навчальний проєкт. Не є офіційною ініціативою університету.

## Можливості MVP
- прийом запитання текстом (Telegram, веб);
- пошук фрагментів у базі документів;
- відповідь з посиланням на джерело; «не знаю», якщо джерела немає;
- оцінка відповіді користувачем.

## Архітектура
Бот -> сервіс пошуку за базою знань -> мовна модель через шар абстракції.

## Технології (планові)
Python 3.11+, python-telegram-bot, FastAPI, pytest.

## Структура репозиторію
docs/   - вимоги, ризики, рішення
src/    - код бота та пошуку
tests/  - тести та набір тестових запитань
